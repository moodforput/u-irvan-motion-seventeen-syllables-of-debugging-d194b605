One haiku about debugging, in the 5-7-5 syllable shape — written by `main.ts`
to `/output/entry.txt` for make.fun's "Seventeen Syllables of Debugging" bounty.

```
cursor blinks at three
log line swears the bug is gone
it moved to line nine
```

Seventy-six characters, seventeen syllables, three lines: a cursor blinking
at 3 a.m., a log line that swears the bug is gone — and the turn: the bug
only moved to line nine.
